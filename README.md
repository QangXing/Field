# Field Lab

Android 端 2D 场模拟沙盒：在俯视世界里摆放电荷、磁体、质量体、阻力区与均匀力场，观察探针粒子在电场、磁场、重力场、引力场、阻力场中的运动。

- 平台：Android 原生（Kotlin + Jetpack Compose，横屏优先，minSdk 26）
- UI：Mindustry 风格（深色直角面板、黄色强调色、底部工具带、就地编辑）
- 放置：工具带槽位放置**场单元**，支持幽灵预览、拖拽连放、45° 旋转、网格吸附与合法性校验
- 图标：每类场一枚白色极简标识（24×24 SVG），源文件见 [`assets/icons/fields/`](assets/icons/fields/)
- 转场：统一的"黄色斜块划屏"过渡动画
- 特性：场叠加与四种可视化（箭头 / 流线 / 热图 / 轨迹）、存档内操作、JSON v2 场景导入导出

> 当前阶段：设计文档已完成，实现尚未开始。
