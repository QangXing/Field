# Field

浏览器中的 2D 物理模拟器 / 刚体沙盒：打开即玩，支持拖拽交互、关节、场景导入导出与确定性回放。

> 当前阶段：设计文档已完成，实现尚未开始。

## 文档

- [设计文档（v0.1）](docs/DESIGN.md)

## 规划

| 里程碑 | 内容 |
| --- | --- |
| M0 | 工程骨架（Vite + TypeScript + Vitest + CI） |
| M1 | 物理核心（宽相 / 窄相 / 顺序冲量求解 / 休眠） |
| M2 | 渲染与交互（Canvas 2D、相机、拖拽） |
| M3 | 关节与场景（JSON v1、示例场景） |
| M4 | 打磨、性能优化、发布 |

技术栈：TypeScript + Vite + Canvas 2D，物理引擎自研。
