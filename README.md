# Field Lab

Android 端 2D 场模拟沙盒：在俯视世界里摆放电荷、磁体、质量体、阻力区与均匀力场，放置小球/方块与探针粒子，观察它们在电场、磁场、重力场、引力场、阻力场中的运动。

- 平台：Android 原生（Kotlin + Jetpack Compose，竖屏，minSdk 26，targetSdk 34）
- UI：Mindustry 风格（深色直角面板、黄色强调色、底部工具带、就地编辑、存档内操作）
- 放置：工具带槽位放置**场单元/运动物体**，支持幽灵预览、拖拽连放、45° 旋转、网格吸附与合法性校验；橡皮固定在工具带最右端
- 场设置：选中场后可拖动中心平移、拖动边框缩放，或在检查器里精确输入中心与边框尺寸
- 运动物体：小球/方块，可调质量、带电量、速度与尺寸，支持重心、受力、电流方向与轨迹预测显示
- 世界规则：万有引力、电荷传递、无视反弹、漏电、库仑力、撞后消散、粒子寿命、轨迹线、场箭头、重心显示等 14 项，逐存档保存
- 可视化：箭头 / 流线 / 热图 / 探针拖尾
- 转场：整块黄色斜切滑块滑满屏幕后滑出，覆盖瞬间切页
- 主页背景：可取任意存档的摄像机取景画面
- 存档：命名、预览、存档设置、JSON v3 导入导出，15 秒自动保存
